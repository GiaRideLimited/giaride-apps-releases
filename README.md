this repo only holds release files published automatically by CI.

## Specific versions

Every build also has its own release, named like `user-stg-v0.1.3-b4`, with a file such as
`giaride-user-stg-v0.1.3-b4-23rd-Oct-2026.apk`. See the [Releases](../../releases) page.

- `stg` = staging build (test servers)
- `prod` = production build
- `v0.1.3-b4` = version 0.1.3, build number 4

## Installing

1. Download the APK on your Android phone.
2. Allow "Install unknown apps" for your browser or file manager when asked.
3. Open the file to install. Updates install over the previous version.

Each release lists a SHA-256 checksum so you can confirm the file is untouched.
